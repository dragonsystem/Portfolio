## v1.0.2 — Apple Watch 連携・UI 改善

### Apple Watch 連携

iPhone を取り出さずに記録開始・停止できる Watch アプリを追加。  
iPhone 側・Watch 側のどちらから操作しても `RideRecorder.stop()` を通るよう設計し、`NotificationCenter.rideDidStop` の1点で両デバイスに対応した。

### ルートハイライト表示

過去のツーリングルートを地図上に重ねて表示する機能を追加。  
期間フィルター（3ヶ月 / 6ヶ月 / 1年 / 全期間）で絞り込みが可能。  
記録中はハイライトを自動でオフにし、現在の記録ラインとの混同を防ぐ。

### ルートラインの色設計

| 状態 | 色 | 意図 |
|---|---|---|
| 記録中 | 赤（`#C0392B`） | 危機感・注目 |
| 詳細画面 | オレンジ（`#FF8800`） | 見やすさ優先 |
| 過去ルート | titanium 40% | 控えめに |
| ハイライト | アンバー（`#FFAA00`） | 強調 |

## v1.0.3 — フィルター・iCloud・バックアップ（2026-05）

### RIDES 期間・エリアフィルター

#### 意思決定

| 問い | 選択 | 理由 |
|---|---|---|
| デフォルト表示 | 全件（すべて） | 利用頻度が少ない段階で「今月」にするとゼロ件になるリスクを避けるため |
| フィルター粒度 | 固定期間 + カスタム期間（後から追加） | 実装コストを Phase 1 / 2 に分離するため |
| フィルター永続化 | `@AppStorage` | アプリを閉じても設定を保持したい |
| 記録停止後の挙動 | フィルターをリセット | 記録後に最新データを必ず見せるため |
| エリア抽出方法 | `ride.area` を `→` で分割して個別マッチ | 「北海道 × 今年」のような複合条件に将来対応できる設計 |

#### フィルター UI

- チップバーで期間を選択（今週 / 今月 / 今年 / カスタム / すべて）
- エリアは記録済みのものだけがドロップダウンに表示
- フィルター適用中は「今月 · 北海道  3件」形式のサマリーバーを表示
- 解除は ×ボタンまたはサマリーバー下の「フィルターを解除」

### iCloud 同期

#### 意思決定

| 問い | 選択 | 理由 |
|---|---|---|
| 同期方式 | CloudKit（`cloudKitDatabase: .automatic`） | 開発者の運用コスト（金銭・作業）ゼロ。Firebase 等の独自サーバーは却下 |
| VersionedSchema | 廃止し自動軽量マイグレーションへ | 同一モデルクラス参照で "Duplicate version checksums" が発生するため |
| `deleteRule` | `.cascade` → `.nullify` | CloudKit が cascade 非対応のため。削除時は子オブジェクトを先に明示削除 |

#### CloudKit Production デプロイ

CloudKit Console の「Deploy Schema Changes...」から Development → Production へ。  
Production スキーマの変更は非可逆（フィールド削除・型変更不可）のため、v1.0.3 提出前にデプロイ済み。

### JSON バックアップ

#### 意思決定

| 問い | 選択 | 理由 |
|---|---|---|
| インポート挙動 | UUID マージ（REPLACE ではない） | 誤って二重インポートしてもデータが重複しない安全設計 |
| UI の配置場所 | STATS タブ → 歯車ボタン → SettingsView | タブを増やさずに既存の画面構成を維持するため |

### レシート OCR 強化

給油記録の自動入力精度向上のため、`ReceiptScanner` を大幅強化した。

| 追加フィールド | 抽出方法 |
|---|---|
| 店舗名 | ブランドキーワード一致 → 店舗指標を含む行 → 先頭5行（3パス方式） |
| 支払い方法 | 現金優先 → 具体的決済ブランド → クレジット一般 → マスクカード番号 → カード単体（優先度5段階） |
| 店舗住所 | 都道府県 → 郵便番号 → 市区町村+番地の順でマッチ |

### 長押しシートの空白バグ修正

`.sheet(isPresented:)` + `if let coord` のタイミング問題で、シートが初回空白になるバグが発生。  
`LongPressCoordinate: Identifiable` ラッパーを導入し、`.sheet(item:)` パターンに変更して解決した。
