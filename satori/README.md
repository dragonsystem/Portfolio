# SATORI

> 選択したフレームの構造を AI で解析し、ワンクリックで直す Figma プラグイン

**公開範囲**: 組織内リリース（Figma Community には公開していない）

---

## 概要

エンジニアに渡す前のデザインデータには、名前のないレイヤー、Auto Layout を使っていない配置、不要なグループなど、見た目には問題がなくても実装しにくい構造が残りがちである。
SATORI は、選んだフレームの**画像**と**レイヤー構造（JSON）**を一緒に Gemini に渡して解析し、問題を見つけて、その場で直せるようにする。

「SATORI（悟り）」は、仏教の「直観的に理解する」から。デザインを監査するもう 1 本のプラグイン [SAKSHI](../sakshi/) と対になっている。

| プラグイン | 役割 | 視点 |
|---|---|---|
| **SATORI** | 1 フレームの構造を直す | 虫の目 |
| **SAKSHI** | デザインシステムに沿っているかを監査する | 鳥の目 |

**開発期間**: 2026年6月  
**開発形態**: 個人開発（AI を活用）  
**対応環境**: Figma

---

## 主な機能

| 機能 | 概要 |
|---|---|
| **AI による構造解析** | 画像とレイヤー構造を同時に渡し、「何のための UI か」をふまえて問題を指摘 |
| **3 種類の問題の検出** | 名前のないレイヤー / Auto Layout を使っていない配置 / 不要なグループ |
| **ワンクリック修正** | 名前の変更 / Auto Layout の適用 / グループ解除 |
| **まとめて修正** | 直したい項目を選んで一括で適用。適用前に Figma のバージョン履歴を自動保存 |
| **コンポーネント化の提案** | 似た構造の要素をコンポーネントにまとめるよう提案 |
| **信頼度の表示** | AI がどのくらい自信を持っているかを表示し、低いときは注意を出す |
| **書き出し** | 解析結果を Markdown で保存。指摘の言語は日本語 / 英語を選べる |

## 技術スタック

| 分類 | 技術 |
|---|---|
| 言語 | TypeScript |
| プラットフォーム | Figma Plugin API |
