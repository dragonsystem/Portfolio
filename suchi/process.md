## 実機フィードバック期 — UI の作り込み（2026-07-05〜07-06）

計画書チケットの実装完了後、実機での使用感を詰めた。計画外の調整を時系列で実施。

### 長押しピンの精度・体感（このフェーズの中心テーマ）

実機で試すと「ピンが意図した位置と少しズレる」「二本指操作のとき引っかかる」問題が発覚。

| 問題 | 解決策 |
|---|---|
| ピン設置位置のズレ | ジェスチャーを Map 直下に付与（座標系のズレ防止）|
| 指の知覚とのズレ | タッチ座標を上に 22pt 補正して変換 |
| 設置の確信が持てない | ライブプレビューピン（0.3秒成立時点でピンが追従表示） |
| 操作の可視性 | 押下フィードバックリング（0.1秒静止→0.2秒で満ちて設置） |
| 二本指での引っかかり | `.gesture` → `.simultaneousGesture` に変更 |

### コンパス

純正 `MapCompass(scope:)` のオーバーレイ表示が重かったため、自前の軽量ダイヤ針に置換。  
北向きリセットは `.region` 方式が不発になる問題があり、**方位を 0 にした `MapCamera` を設定**する方式に変更した。

### ナビ画面 — 横向き対応

`headingOrientation` を固定から `UIDevice` の向き通知に追従させた。横向き時に矢印が 90 度ズレる問題への対策。

### コンパス調整警告の誤検出解消

「Heading が 5 秒途絶」の判定では直進・静止中に誤検出が多発した。  
**`headingAccuracy` が無効または誤差 30 度超の状態が 3 秒継続**したときだけ警告を出すよう変更した。

### 意思決定ログ（主要なもの）

| 問い | 選択 | 理由 |
|---|---|---|
| ダークモードの強制トグル | OS がダーク時は `.disabled` + 淡色化 | 二重設定は無意味なため |
| 目的地ピンのデザイン | Material Symbols `location_on` を `LocationPinShape` へ移植 | グラデーション + 中央穴の even-odd 透過で地図上の標準ピンらしさを実現 |
| 走行記録タイトル | 距離表示やめ → 日付ベース + 同日連番 | 距離はカードに別表示するため、タイトル的に見せる必要がない |
| 再ナビ実現 | `destinationLat`/`destinationLon` を RouteLog に保存 | 履歴から出発地・目的地・終了地点を再利用するため |

## 多言語対応（v1.0.2）2026-07-22〜07-27

英語 UI の実装（Ticket L-1〜L-12）。

### 主な実装内容

| チケット | 内容 |
|---|---|
| L-1〜L-2 | String Catalog 導入。`developmentRegion` を `en` → `ja` に是正 |
| L-3〜L-6 | 全画面の UI 文言を String Catalog へ抽出（計 97 キー） |
| L-7 | 16 方位をローカライズ（`compass.*`）。0°/359° のラップアラウンドを検証 |
| L-8 | 距離単位を「地域（`Locale.current.measurementSystem`）」に追従（m/km ⇔ ft/mi）|
| L-9 | 位置情報の権限説明文を `InfoPlist.xcstrings` へ |
| L-10 | 設定メニューに「言語」項目を追加し `openSettingsURLString` で iOS 設定へ誘導 |
| L-11 | 未翻訳の洗い出しで実バグ 3 件を検出・修正 |
| L-12 | ストア文言の英語版・公開ページの日英併記・英語版スクリーンショット 8 枚 |

最終的に String Catalog は **118 キー**。日本語環境の表示は v1.0 と一字一句一致（回帰なし）を各チケットで確認。

### App Store Connect での英語登録でつまずいた点

英語ロケールの「配信」ページだけを埋めて保存しても、赤い未保存アイコンが消えず、ハードリロードで英語入力が全消えする現象が発生。

**原因**: 「アプリ情報」ページ（アプリ名・サブタイトルのロケール別設定）を先に保存していなかったため。  
**解決**: ①「アプリ情報」で英語アプリ名を先に保存 → ②「配信」ページの残り項目を保存、の順で解決。

> **申し送り**: 3 言語目以降は、先に「アプリ情報」でアプリ名を保存してから「配信」ページに進むこと。

2026-07-27、v1.0.2 を審査提出完了。
