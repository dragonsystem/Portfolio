# SUTRA

> デザイントークンと連動する、Figma 用の UI コンポーネント・ワイヤーフレーム生成プラグイン

[![Figma Community](https://img.shields.io/badge/Figma_Community-公開中-blue?logo=figma)](https://www.figma.com/community/plugin/1652926105517784439/sutra)

---

## 概要

ボタンや入力欄からダッシュボード全体のレイアウトまで、UI コンポーネントを Figma のキャンバスにすぐ生成するプラグイン。
最初は白黒のワイヤーフレームとして使い始め、ブランドカラーや間隔などのトークンを決めていくと、そのまま Figma Variables と連動したデザインシステムへ移れる。

**開発期間**: 2026年6月〜（2026年6月28日 v1.0 公開、開発は継続中）  
**開発形態**: 個人開発（AI を活用）  
**対応環境**: Figma（デスクトップ / ブラウザ）

---

## 主な機能

| 機能 | 概要 |
|---|---|
| **コンポーネント生成** | Atomic Design の階層（Atom / Molecule / Organism / Module）で 90 種以上のコンポーネントと、ページ全体のレイアウトテンプレートを生成 |
| **Token Store** | ブランドカラー 4 色・間隔の基準値・角丸・フォントを入力すると、全コンポーネントの見た目が一括で切り替わる |
| **Figma Variables 同期** | トークンを Figma の Variables（Primitive / Semantic の 2 層、Light / Dark モード）として書き出し、コンポーネントに紐づける |
| **トーン自動生成** | 1 色のアンカー色から、Hover・Pressed・Container・文字色まで 10〜23 段階の色を自動で計算 |
| **コントラスト検証** | 色を変更したとき、文字と背景のコントラスト比が WCAG AA を下回る組み合わせを警告 |
| **手動変更の保護** | Figma 上で手動変更された Variables をトークン保存時に検知し、項目ごとに上書きするか残すかを選べる |
| **書き出し** | W3C Design Tokens 形式の JSON、CSS カスタムプロパティ、スタイルガイド、Code Connect 用のスタブを出力 |
| **ガイドラインページ** | 全コンポーネントを一覧できるページを Figma 上に展開 |
| **日本語での検索** | 「目的から探す」タブと、カタカナとひらがなを区別しないキーワード検索 |

## 技術スタック

| 分類 | 技術 |
|---|---|
| 言語 | TypeScript |
| プラットフォーム | Figma Plugin API |
| ビルド | esbuild |
| テスト | Vitest（Figma API に依存しない計算ロジックを単体テスト） |
| 色の計算 | HSL ベースのトーン計算、WCAG 相対輝度・コントラスト比（自作） |
| ネットワーク | なし（`networkAccess: none`。データを外部に送らない） |

規模（公開版）: TypeScript 約 15,000 行。コンポーネントごとの詳細設計書 60 件以上。

## 開発中（未公開）：React 出力

公開版とは別に、開発版で **Figma のコンポーネントを React + Tailwind のコードとして書き出す機能**を進めている（2026年8月〜）。

- 2026-10 時点で 55 件のコンポーネントを出力できる
- 書き出したコードは、実際の React プロジェクトで構文・型チェック・描画まで通ることを確認
- Figma 側のデザイン（色・寸法・枠線・hover の色など）と出力コードがずれていないかを自動で検査
- 出力に「部品の説明書」（manifest）を同梱し、AI が読んで部品を正しく使えるようにする

規模（開発版）: TypeScript 約 27,000 行、テスト約 350 件。詳細は [開発プロセス](./process.md#公開後の開発未公開) を参照。
